Study tool · an AI agent as tutor

Dutch tutor

My Dutch textbook is written entirely in Dutch, so I set up an AI agent to tutor me from it. It explains each chapter in English first, quizzes me on the fly, and says the Dutch out loud.

Smaller tools

Layout-preserving PDF translation

An agent skill that translates a Dutch PDF into English and keeps the page intact. It lifts each text block with its position and font, removes the original text, and sets the translation back into the same boxes, so images, signatures and page numbers stay where they were. It fails loudly if a paragraph goes missing.

Cineville cinema map

Scrapes every cinema in the Dutch Cineville pass (about 80) and exports them as a map layer. Google has no API for saved lists, so the project documents the options that do work and picks the cheapest: a KML import.
